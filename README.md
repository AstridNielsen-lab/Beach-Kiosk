## **📌 Sobre o Projeto**  
O **Quiosque Manager** é um sistema completo para gestão de **quiosques de praia**, bares e estabelecimentos similares, permitindo um gerenciamento eficiente de pedidos, estoque e atendimento ao cliente.  

Este aplicativo possui **duas versões**:  
- **Versão Cliente** → Interface intuitiva para clientes realizarem pedidos de bebidas e petiscos.  
- **Versão Administrativa** → Painel para gerenciamento dos pedidos, envio automático para cozinha e bar, além de relatórios de vendas e controle de estoque.  

## **🚀 Funcionalidades**  
✅ Cardápio digital com imagens e preços.  
✅ Adição de itens ao carrinho e finalização de pedidos.  
✅ Acompanhamento do status do pedido em tempo real.  
✅ Separação automática de pedidos entre **cozinha e bar**.  
✅ Controle de estoque e relatórios de vendas.  
✅ Painel administrativo para gerenciamento completo do quiosque.  
✅ Interface **responsiva e otimizada** para dispositivos móveis.  

## **💻 Tecnologias Utilizadas**  
🔹 **Backend:** C# (.NET) – Escalável e seguro.  
🔹 **Frontend:** HTML, CSS, JavaScript (React.js ou Vue.js).  
🔹 **Banco de Dados:** SQL Server.  
🔹 **Infraestrutura:** API REST para comunicação entre cliente e servidor.
